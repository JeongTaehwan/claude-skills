# Building a StoryBrand (Donald Miller)

https://storybrand.com/

## 한 줄
Donald Miller, 2017 — 브랜드 메시지를 이야기 구조로 짜되 **주인공 자리에 브랜드가 아니라 고객을 앉히고 브랜드는 가이드 역할을 맡는다**는 원칙과, 그것을 7단계 프레임(SB7)으로 고정해 홈페이지·이메일·세일즈 문구를 한 벌로 뽑아내는 실무서.

## 페르소나
**홈페이지 히어로 영역에 "우리는 10년 경력의 팀이 만든 차세대 통합 플랫폼입니다"라고 써 놓고 전환율이 안 나오는 것을 고민하는 팀.** 문장은 문법적으로 멀쩡하고 회사 소개로도 정확한데, 방문자는 3초 안에 "내 문제가 여기서 풀리나"를 판정하고 떠난다. 회사 이야기를 고객의 문제 서술로 뒤집는 구체적인 틀 — 어떤 문장을 어느 자리에 놓아야 하는지까지 — 이 필요한 상황이다.

## 이럴 때 연다
- 랜딩페이지·홈페이지 히어로 카피를 처음부터 다시 쓸 때
- 온보딩 이메일 시퀀스나 세일즈 덱의 서사 순서를 정할 때
- 팀마다 제품 소개 문장이 달라 하나로 수렴시켜야 할 때
- 기능 나열형 카피를 문제·해결 서사로 바꿔야 한다는 것을 팀에 설득할 때
- 명확한 CTA 하나를 고르고 나머지를 정리해야 할 때
- 마케터가 아닌 사람(창업자·엔지니어)이 직접 카피를 써야 하는 상황에서 채워 넣을 틀이 필요할 때

## 이럴 땐 아니다
- 카피 이전에 **어떤 카테고리로 소개할지**가 안 정해졌다면 `marketing/obviously-awesome-april-dunford.md`
- 경쟁 구도 안에서의 자리 잡기 원리는 `marketing/positioning-ries-trout.md`
- 메시지가 기억되고 전달되는 속성(구체성·의외성) 자체를 다루려면 `marketing/made-to-stick-heath-brothers.md`
- 입소문이 왜 도는지의 연구 기반 설명은 `marketing/contagious-jonah-berger.md`
- 설득 문구가 아니라 **채널 선택**이 병목이면 `marketing/traction-weinberg-mares.md`
- 카피 변형의 효과를 검증하는 실험 설계는 `planning/a-b-testing.md`, `planning/trustworthy-online-controlled-experiments.md`

## 무엇이 들어있나
SB7 프레임의 일곱 요소는 다음과 같다 — (1) 무언가를 원하는 **캐릭터(고객)**, (2) 그가 마주한 **문제**(외적 문제·내적 문제·철학적 문제로 나눔), (3) 그를 돕는 **가이드(브랜드)**, (4) 가이드가 주는 **계획**, (5) 행동을 요구하는 **콜 투 액션**, (6) 실패했을 때의 결과, (7) 성공했을 때의 변화된 모습.

이 틀의 실무적 가치는 두 가지 규칙으로 압축된다. 첫째, **브랜드는 주인공이 아니라 가이드다.** 회사 연혁·수상·기술 스택으로 시작하는 카피는 주인공 자리를 브랜드가 뺏은 형태이고, 고객은 자기 이야기가 아닌 것에 몰입하지 않는다. 둘째, **문제를 외적/내적으로 나눈다.** 외적 문제는 "정산이 수작업이라 오래 걸린다", 내적 문제는 "매달 마감 때마다 실수할까 봐 불안하다"이다. 대부분의 카피가 외적 문제만 말하고 구매를 실제로 밀어붙이는 내적 문제를 비운다는 지적이 이 책에서 가장 실용적인 대목이다.

또 하나 강하게 밀어붙이는 규칙은 **CTA 를 하나로 줄이라**는 것 — 주 CTA(구매·상담 신청)와 부 CTA(자료 다운로드 등)를 구분하고, 화면 안에서 같은 위계의 버튼을 여러 개 두지 말라고 한다.

사이트(storybrand.com)는 책과 함께 브랜드스크립트 작성 도구, 워크숍, 인증 가이드 프로그램을 파는 상업 서비스다 — 유료 상품이 전면에 있고, 프레임의 요약과 사례는 무료로 볼 수 있다. 이 책은 근거를 제시하는 연구서가 아니라 실무 템플릿이므로, "이 구조가 전환을 얼마나 올린다"는 식의 수치를 인용하지 말고 **문장 구조를 정하는 체크리스트**로 쓰는 것이 안전하다.

## 인용 포인트
- 회사 소개형 히어로 카피를 고객 문제 서술로 바꾸자는 제안의 근거 — "브랜드는 가이드, 고객이 주인공".
- 카피 리뷰에서 "외적 문제만 있고 내적 문제가 없다"는 지적을 구조적 결함으로 제기할 때.
- 한 화면에 CTA 를 여러 개 두려는 요구를 주 CTA/부 CTA 위계로 정리할 때.
- 마케터가 없는 팀에 카피 작성 절차를 넘겨줄 때, 채워 넣기만 하면 되는 7칸 틀로서.
