# Semantic Versioning

https://semver.org/

## 한 줄
MAJOR.MINOR.PATCH를 "감각"이 아니라 규칙으로 못 박은 짧은 명세 — 버전 번호를 올리는 조건이 공개 API의 호환성 변화로만 정의된다.

## 페르소나
**사내 공용 라이브러리나 API를 관리하다가 "이거 메이저 올려야 하나요?"라는 질문을 매번 받는 사람.** 필드를 하나 추가했을 뿐인데 소비 팀이 깨졌다는 연락을 받았거나, 반대로 사소한 변경마다 메이저를 올려서 아무도 업그레이드를 안 하는 상태다. 판단 기준을 개인 취향이 아니라 문서로 팀에 걸어두고 싶다.

## 이럴 때 연다
- 사내 공용 모듈·SDK·결제 클라이언트의 버저닝 정책을 처음 문서화할 때
- "이 변경이 breaking change인가"를 두고 리뷰에서 의견이 갈릴 때
- 0.y.z 단계에서 계속 머무를지, 1.0.0을 선언할지 결정해야 할 때
- 프리릴리스(`1.0.0-beta.1`)나 빌드 메타데이터(`+build.5`) 표기법의 정확한 문법이 필요할 때
- 의존성 범위 표기(`^`, `~`)가 왜 그렇게 동작하는지 근거를 설명해야 할 때

## 이럴 땐 아니다
- 버전 번호가 아니라 릴리스마다 무엇이 바뀌었는지 사람이 읽는 기록을 정리하려면 `development/keep-a-changelog.md`
- 커밋 메시지에서 버전 상승을 자동 판정하고 싶다면 그 규약은 `development/conventional-commits.md` 쪽이다
- HTTP API의 버저닝(경로 `/v1` vs 헤더, 필드 추가의 하위호환) 설계 판단은 `development/google-api-design-guide.md`

## 무엇이 들어있나
핵심 주장은 하나다 — 버전 번호는 마케팅이나 규모의 표현이 아니라 **공개 API 호환성에 대한 계약**이다. 그래서 "큰 기능이 들어갔으니 메이저"는 명세 위반이고, "한 줄 고쳤으니 패치"도 그 한 줄이 호환을 깨면 틀린 것이다.
전제 조건도 명시적이다. SemVer를 쓰려면 먼저 공개 API가 무엇인지 선언되어 있어야 한다. 이게 안 되어 있으면 규칙 적용 자체가 불가능하다.
0.y.z는 "아무것도 약속하지 않는 구간"으로 규정되어 있고, 1.0.0을 찍는 순간부터 계약이 시작된다. 실무에서 0.x에 오래 머무는 라이브러리가 많은 이유가 여기 있다.
릴리스된 버전의 내용은 절대 수정하지 않고 새 버전으로 낸다는 조항, 프리릴리스·빌드 메타데이터의 우선순위 비교 규칙까지 짧게 다 들어 있다. 전체가 한 페이지라 팀 위키에 그대로 링크해도 부담이 없다.

## 인용 포인트
- "이건 기능 추가라 마이너다"라는 주장에 대해, 기존 동작이 하나라도 바뀌면 메이저라는 명세 조항을 근거로 되물을 수 있다.
- 1.0.0 선언을 미루는 팀에게 "0.x는 소비자에게 아무 보장도 하지 않는 구간"이라는 규정을 보여주면 논의가 진전된다.

## 코드 예시

명세의 전제인 "공개 API 가 먼저 선언되어 있어야 한다"를 파일 하나로 못 박은 형태 — `exports` 바깥의 파일은 계약이 아니므로 바꿔도 패치다.

```json
{
  "name": "@acme/payments",
  "version": "2.4.1",
  "exports": {
    ".": "./dist/index.js",
    "./errors": "./dist/errors.js"
  },
  "files": ["dist"],
  "dependencies": {
    "@acme/core": "^3.1.0",
    "@acme/http": "~1.2.3"
  },
  "peerDependencies": {
    "typescript": ">=5.0.0 <6"
  }
}
```

`^3.1.0` 은 `<4.0.0`, `~1.2.3` 은 `<1.3.0` 을 뜻한다 — 범위 표기가 이렇게 생긴 이유가 곧 SemVer 계약이다. 함정은 0.x 다. `^0.2.3` 은 `<0.3.0` 으로 좁게 해석되는데, 이건 도구가 "0.y.z 는 아무것도 약속하지 않는 구간"이라는 명세를 반영한 결과다. 1.0.0 을 안 찍고 버티는 라이브러리에 `^` 를 붙여 두면 실제로는 마이너 업그레이드조차 자동으로 안 올라온다.
