# 끼니 (Kkini) — 제품 브리프

> 상태: 초안 (2026-09-12). 에이전트 팀이 공유하는 출발점이다. 사람이 말한 것과 작업 가정을 분리해 둔다.

## 사람이 말한 것 (원문 요지)

"매일 끼니 해결 관련 추천해주는 앱. 저녁 식사 고민될 때 해주는 것."

그 외에는 아무것도 정해지지 않았다.

## 작업 가정 — 사람 승인 전. 문서에서는 `[제안]`으로 표기한다

- 가칭 **끼니 (Kkini)**. 레포 이름도 `kkini`.
- 시장은 한국, 언어는 한국어.
- 첫 범위는 **저녁 한 끼**. 아침·점심·간식은 범위 밖 후보.
- 해결 방식은 세 갈래를 모두 다룬다 — 집에서 해 먹기 / 배달·포장 / 나가서 먹기.
  어느 갈래를 MVP에 넣을지는 미정이며 등급을 매긴다.
- 핵심 가치 가설: 선택지를 많이 보여주는 것이 아니라 **결정을 대신 해주는 것**.
  고민 시간이 줄어드는 것이 성공이다.
- 개발은 사람 1명 + Claude Code 에이전트 팀. 운영비 최소, 관리형 서비스 선호.
- 플랫폼(웹/PWA/네이티브), 스택, 수익화는 전부 미정.

## 문서 규칙 (role-isolation-pipeline 컨벤션)

- 한국어. 요구사항은 한 줄에 하나, 참/거짓을 판정할 수 있는 문장.
- 사람이 정하지 않은 것을 확정처럼 쓰지 않는다.
  - 에이전트의 제안은 `[제안]` + 한 줄 이유.
  - 사람이 정해야 하는 것은 `[미정]` + BLOCKER/LATER 등급 + 구체적으로 막히는 증상.
- 근거를 못 대는 사실 진술에는 `[추정]`.
- 화면·기능마다 두 글자 약칭. 미정 질문 ID는 `XX-OQ-NN`, 절차 문제는 `PROC-OQ-NN`.
