# 미정 사항 — 끼니(Kkini)

> 해결된 항목을 삭제하지 않는다 — 상태를 `해결·승인: <한 줄 결정>`으로 바꾼다. 전제가 사라진 항목도 지우지 않고 `폐기 (...)`로 남긴다.
> 아래 `추천:`은 에이전트 제안이다. 사람이 고르기 전까지 상태는 `[미정]`으로 남는다. **해결·승인된 항목의 옛 `추천:` 줄은 상태 칸의 사람 답이 대체한다.**
> 갱신: 2026-09-12 (v1) — 사람의 2차 진술과 질문 5개 답을 반영. 근거 표기 `2차 진술` / `답1`~`답5`는 `docs/requirements.md` 0절과 같다.
> 질문 축 7개 — (1) 답하는 질문 하나 (2) 데이터 주인 (3) 기준과 분모 (4) 범위 밖 (5) 모르는 값의 표기 (6) 상태 (7) 제약.
