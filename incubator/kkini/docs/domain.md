# 도메인

> 이 프로젝트가 이미 내린 결정과 용어의 단일 출처. **사람이 관리한다** — 구현자와
> 검증 AI는 수정하지 않는다. 검증 AI는 여기 적힌 것을 다시 묻지 않고, 어긋나는 것을 찾는다.

처음에는 비어 있어도 된다. `docs/requirements.md` 승인이 반복되며 여러 화면에 걸쳐
굳은 것을 사람이 여기로 승격한다.

들어갈 것:

- **용어 정의** — 같은 말이 두 가지로 읽힐 수 있으면 여기서 확정한다
- **확정된 계산 규칙·기준** — 기간, 분모, 반올림, 판정 기준
- **화면이 말해야 하는 상태 목록** — 빈 값 / 로딩 / 실패 / 표본 부족 / 미확정 등,
  이 제품에서 각 상태에 뭐라고 쓰는지
- **외부 의존과 한계** — 요금제, 쿼터, 호출 한도, 데이터 갱신 주기
